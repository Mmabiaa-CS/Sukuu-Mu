## Sukuu Mu v1.1.0 Release Notes

Release date: 2026-04-25

### Highlights

- Added a new **Settings** page at `dashboard/settings`
- Added **theme switching** (Light and Dark mode) based on user preference
- Enabled **PWA support** with install flow and service worker
- Added user preference storage for selected app settings

### What is new

#### 1) Dashboard Settings Page

- New route: `client/app/dashboard/settings/page.tsx`
- Settings page follows the same dashboard visual style used across existing pages
- Features included:
  - Theme mode controls (Light / Dark)
  - App install card (PWA install status and action)
  - User preference toggles:
    - Email notifications
    - Reduced motion
    - Compact tables

#### 2) Theme System

- Global theme provider integrated in `client/app/layout.tsx`
- Uses `next-themes` with persisted preference
- Light/Dark mode can be switched by users in Settings

#### 3) Progressive Web App (PWA)

- Added manifest: `client/public/manifest.webmanifest`
- Added service worker: `client/public/sw.js`
- Added service worker registration component: `client/components/pwa-register.tsx`
- Layout metadata now includes app manifest and app-like metadata for installability

### Technical changes

- Sidebar updated to include **Settings** menu item:
  - `client/components/dashboard-sidebar.tsx`
- App layout updated with:
  - `ThemeProvider`
  - `PwaRegister`
  - manifest/app metadata

### Upgrade notes

- If users previously loaded older app versions, they may need one hard refresh to pick up the new service worker and manifest.
- PWA install availability depends on browser support and HTTPS requirements in production.

### Known limitations

- Current icon set uses existing SVG icon assets; dedicated 192x192 and 512x512 PNG icons are recommended for best install compatibility across all platforms.
