## Sukuu Mu v1.0.0 Release Notes

Release date: 2026-04-20

### Highlights

- First production-ready baseline release of the Sukuu Mu web app
- Delivered role-based authentication and protected dashboard routing
- Added core school management modules: Students, Classes, Subjects, and Teachers
- Introduced attendance recording and finance tracking foundations

### What is new

#### 1) Authentication and access control

- Login flow with redirect behavior for authenticated and unauthenticated users
- Protected dashboard layout using route guards
- Role-aware sidebar navigation and page access rules

#### 2) Dashboard and navigation shell

- Unified dashboard UI layout with persistent sidebar and content area
- Overview page with key school operation stats and quick actions
- Role-specific visibility for operational modules

#### 3) Academic and people modules

- Students module:
  - Searchable student directory
  - Add/edit student flows
  - Student profile details page
- Classes module:
  - Searchable class list
  - Create/edit class flows
  - Enrollment and capacity indicators
- Subjects module:
  - Searchable subject catalog
  - Create/edit subject flows
- Teachers module:
  - Searchable teacher list
  - Create/edit teacher flows
  - Subject association display

#### 4) Operations modules

- Attendance module:
  - Class/date selection
  - Mark present/absent/late per student
  - Bulk mark-all-present and summary dialog
- Finances module:
  - Fee and payment listing
  - Payment recording flow
  - Receipt number generation

### Technical notes

- Built on Next.js App Router structure under `client/app`
- Frontend designed around RBAC and school-domain entities
- Data layer supports mock-mode operation while backend integration evolves

### Known limitations

- No in-app user settings/personalization screen in this version (added later in v1.1.0)
- PWA install flow is not included in this version (added later in v1.1.0)
